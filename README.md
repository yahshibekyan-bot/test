# Life Kanban

Простой локальный канбан-сервис для 10 направлений жизни.

## Запуск

```bash
python -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000).

## Возможности

- 10 направлений жизни с трёхколоночным канбаном.
- Создание, изменение статуса и удаление карточек.
- Сохранение данных в `localStorage`.
